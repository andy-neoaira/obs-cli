- `path/to/file.go`

## 执行前检查

```bash

go test ./path/to/package
```

记录基线结果和已有用户改动。不得覆盖不属于本任务的修改。

## 执行步骤

1. 增加最小失败测试，证明问题可以稳定复现。
2. 实现最小修复，不扩大公共 API。
3. 运行定向测试并检查失败路径。
4. 运行相关包和 race 测试。
5. 更新规范、任务状态和完成证据。

每一步完成后记录：

- 修改内容
- 验证命令
- 验证结果
- 尚存风险

## 验收标准

- [ ] 问题的失败测试在修复前失败、修复后通过。
- [ ] 正常路径、错误路径和边界输入均有覆盖。
- [ ] 未改变“非目标”中列出的行为。
- [ ] `git diff --check` 通过。
- [ ] 定向测试和 `go test -race` 通过。
- [ ] 文档、Schema 与实现一致。

## 验证命令

```bash

go test -race ./path/to/package

```
